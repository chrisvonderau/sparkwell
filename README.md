# Sparkwell

A thunderstorm-carnival pinball table.

Play it in the browser on this repository's GitHub Pages site.

One self-contained offline HTML file (`index.html`): no login, no ads, no analytics, no network calls. Works on MacBook (Safari or Chrome) and iPad.

## Xbox / gamepad controls

- LB / RB: left / right flipper
- RT (analog) or A: charge and release the plunger
- Left stick or d-pad: nudge
- Y: helper arrows · X / View: table extras
- Start (Menu): pause
- Any button on the title or game-over screen: start

The title screen shows a **Controller:** status line. If it says *none detected*, pair the controller in Bluetooth settings and press any button on it (browsers only reveal a pad after a button press). Chrome may hide controllers on pages opened from a local file, so use the GitHub Pages link.

## Keyboard, trackpad and touch

- Z / Left Shift: left flipper · / or Right Shift: right flipper · Space or Down: plunge · Arrows: nudge · H: helpers · Esc: pause
- Touch buttons on iPad
